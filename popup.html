ChatGPT Chrome Extension

Chat Token Counter

This extension runs automatically on chatgpt.com and shows a floating token counter in the bottom-right corner.

  • Open ChatGPT and start typing, or open an existing conversation.
  • Click the floating widget to cycle compact, expanded, and collapsed views.
  • After code changes, reload the extension in chrome://extensions and refresh ChatGPT.

Supported sites: chatgpt.com, chat.openai.com
